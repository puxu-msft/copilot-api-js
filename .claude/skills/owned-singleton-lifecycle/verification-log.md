## 投票规则

本文件是本 skill 记录协议的**唯一权威**；SKILL.md 只定义断言，不复述规则。

- **一条断言被三次独立会话证实即毕业**（移到「已毕业」节）；**任何一次证伪都当场改 SKILL.md 正文**，并在这里写清改了什么。
- **数据不足也要写。** 长期观察不到说明验法选错了位置，那就**改验法，优先于改结论**。
- **改过本 skill 的会话不能投证实票。** 机械判据：`git log --oneline -5 -- .claude/skills/owned-singleton-lifecycle/` 里有你本会话的提交，或你这轮编辑过该目录 → 本轮只能记「数据不足」或「证伪」。
- **证伪票不受此限，而且格外可信**：作者证伪自己的产物是逆着确认偏误走的。
- 三次证实票须来自**三个未编辑过本 skill 的会话**。
- **V2（判适用边界）需要负样本才能计票**：只有在「对象是纯值缓存」的场景里观察到它明确判定不适用，才算一次证实；资源型单例场景下它适用属于 V1。
