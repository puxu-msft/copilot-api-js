## 投票规则

本文件是本 skill 记录协议的**唯一权威**；SKILL.md 只定义断言，不复述规则。

- **一条断言被三次独立会话证实即毕业**（移到「已毕业」节）；**任何一次证伪都当场改 SKILL.md 正文**，并在这里写清改了什么。
- **数据不足也要写。** 「这次没观察到」本身是信息；长期观察不到说明验法选错了位置，那就**改验法，优先于改结论**。
- **改过本 skill 的会话不能投证实票。** 机械判据：`git log --oneline -5 -- .claude/skills/anthropic-precontent-recovery/` 里有你本会话的提交，或你这轮编辑过该目录 → 本轮只能记「数据不足」或「证伪」。理由是观察被污染，不是人品问题——作者知道该用哪个 skill（污染 V1）、也不会在自己写的边界表前犹豫（污染 V2）。
- **证伪票不受此限，而且格外可信**：作者证伪自己的产物是逆着确认偏误走的。
- 三次证实票须来自**三个未编辑过本 skill 的会话**。
- **V2（不抢邻域）需要负样本才能计票**：只有在「本该走三个邻域 skill 之一」的场景里观察到它**没有**被召回，才算一次证实。B2 场景下它出现属于 V1，不属于 V2。
