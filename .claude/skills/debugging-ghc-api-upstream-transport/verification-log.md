## 记录协议

- 每条格式：`- [V<n>] <日期> <commit/运行实例/request-id> ｜视角：使用者/旁观 reviewer｜观察｜结论：证实/证伪/数据不足`。
- **证实票**必须来自未参与本轮 skill 编写的会话，并给出可复查的真实触发或事故工件；作者、只读文本 reviewer、人工点名 skill 后的执行均只能记“数据不足”。
- **证伪票**不受作者限制：任一次命中证伪形态，都要在同一轮修正文或触发描述，并记录改动。
- 同一断言三次独立证实可标为“已验证于当前环境”，但不删除自验项；runtime／入口／History schema 变化后重新打开观察。
- V2/V3 记录必须写清哪一阶段实际执行、哪一层证据支持什么与不支持什么；“最后修好了”不能代替过程证据。
