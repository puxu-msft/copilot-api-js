### 2.4 流式 pump 骨架（§5.3 + H2/H3 + defensive parse）

`pumpAnthropicStreamingV4`：建 acc（`createAnthropicStreamAccumulator`）+ checkRepetition + serverToolFilter + toolInputDecoder + toolCallTextRecoverer + streamState + heartbeat（**同 legacy setup**），然后：
```ts
for await (const frame of driver.runResponse(upstream, env)) {
  const rawEvent = frame as ServerSentEventMessage                  // SseFrame 结构兼容
  if (!rawEvent.data) { await processOneStreamEvent({rawEvent, parsed: undefined, ...}); continue }   // keepalive
  if (rawEvent.data === "[DONE]") break
  let parsed: StreamEvent | undefined
  try { parsed = JSON.parse(rawEvent.data) as StreamEvent; accumulateAnthropicStreamEvent(parsed, acc) }
  catch (e) { consola.error("Failed to parse Anthropic stream event:", e, rawEvent.data) }            // §12.6 defensive，仍 process
  await processOneStreamEvent({rawEvent, parsed, ...})              // 转发（含 recoverer/decoder/filter/heartbeat）
  if (parsed?.type === "error") break                              // H2：yield-then-break（§11.4，先 process 再 break）
}
// flush（recoverer → decoder，legacy handler.ts:606-614 逐字）
// setSseEvents + setForwardedResponse + (acc.streamError ? ctx.fail : ctx.complete(buildAnthropicResponseData(acc, model)))
// catch（H3 §10.4）：setSseEvents + setForwardedResponse + settleStreamingFailure（client-abort→return）/ logUpstreamStreamError + best-effort flush + 错误帧（heartbeat.writeSerialized）
// finally: heartbeat.stop()
```
**坑**：
- pump 自管 `acc`（import `createAnthropicStreamAccumulator` + `accumulateAnthropicStreamEvent`），**不用** codec 的 `createResponseAccumulator`（那是 P3.2 HistorySink 钩子）。
- **不叠 guard**（transport 已有）；`clientAbortSignal` 只传 heartbeat（让 tick 检查 abort）。
- `env.body` 是 **post-retry env**（C0-①）——recoverer 的 `toolNames`/`toolSchemas` 从 `env.body.tools` 取（deferred-tool retry 改过的 tools 在这里），否则字节差异。
- `sseEvents` 由 pump 自己 push（processOneStreamEvent 内），非 driver 采样（与 CC handler-v4 一致）。

### 2.7 失败 settle（§11.5/M3）+ route flag dispatch

## 6. 坑 / 教训（前序 + explorer 已踩，照搬）

- **不改 byte-critical pump 逻辑**：复用 processOneStreamEvent 等，只换流源为 driver.runResponse + 内联 parse+accumulate+break。
- **不叠 guard**：transport 的 `guardSseIterable` 已含 idle/shutdown/client-abort；pump 内联版不再加（否则双重 abort 监听）。已核验 guardSseIterable 与 processAnthropicStream 在 client-abort 上等价（都 throw StreamClientAbortError，stream.ts:283 vs anthropic/stream.ts:89；过时注释 stream.ts:195-196 顺手修，§10.6/§12.0）。
- **H2 yield-then-break**：upstream 终态 `error` SSE 帧**先 processOneStreamEvent 转发（恰一次）再 break**（§11.4），反了吞帧；loop 后 `acc.streamError ? fail : complete`（CC 无此路径——OpenAI 终态错误是 throw，必须专测）。
- **H3 catch flush**：mid-stream 失败时错误帧**之前** flush recoverer + decoder（否则半构建 tool_use 腰斩）。
- **defensive JSON.parse**（§12.6）：parse 失败仅 consola.error、不 break、仍 process（parsed=undefined），复现 processAnthropicStream try/catch。
- **§12.4 thinking feature 落闭包侧**：beta-stripped/truncated/sanitization 走 onMeta，但 thinking 依赖 env.body.thinking → 走 `codec.getLatestEffectiveThinking()`（易漏）。
- **§12.5 env.body===action.payload**：adapter 不 clone body，sampleRequest 闭包拿到 retry 后 messages。
- **betaProbe 同一实例**注入 codec（prepareWire recordOutbound）+ strategies（unsupported-beta getProbeCandidates）。
- **post-retry env**（C0-①）：pump 读 env.body.tools 建 recoverer——deferred-tool retry 改 tools 后需 post-retry env 才不字节差异。
- **flaky/时序**：fake timers + mock 随机/时钟；连跑 10-25× 确认确定性。
