## 核心问题与修复

### 问题

`/models` 路由违反项目原则 3（数据以最丰富形式流动）：
- `formatModel()` 丢弃 7+ 个上游字段
- 自造 3 个字段（`type`、`created`、`created_at`）
- 重命名 2 个字段（`vendor` → `owned_by`、`name` → `display_name`）

### 修复

- 删除 `formatModel()`、`formatModelDetail()`、`EPOCH_ISO`
- 透传上游全部字段，仅剥离 `request_headers`（内部敏感数据）
- `?detail=true` 保留为向后兼容的 no-op
- `Model` 接口补充 `is_chat_default`、`is_chat_fallback`

### 前端影响

| 链路 | 变更数 | 说明 |
|------|--------|------|
| Vuetify 链（`useModelsCatalog` → `ModelCard` → `ModelsFilterBar`） | 10 | `owned_by` → `vendor`、`display_name` → `name` |
| Legacy 链（`ModelsPage.vue`） | 9 | 同上 |
