## High-5: ServerInstance.close() 跨运行时语义不一致 — ❌ 仍未修复

**代码验证**：`serve.ts:99-103` Bun 分支：
```typescript
close(force?: boolean): Promise<void> {
  bunServer.stop(force ?? false)
  return Promise.resolve()
}
```
`bunServer.stop()` 同步返回 void。`stop(false)` 让现有连接完成但 Promise 不等待完成；`stop(true)` 立即中断但同样不等待。
