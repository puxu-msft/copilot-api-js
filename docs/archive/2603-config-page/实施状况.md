## 审阅过程发现的问题（全部经代码深度验证）

### [HIGH] anthropic 嵌套更新删除兄弟字段（review-260329-2）

**问题**：PUT 请求只发送 `anthropic` 下的部分字段时，未发送的兄弟字段被解构为 `undefined`，`setScalar()` 将 `undefined` 视为"删除"，导致其他 anthropic 配置项丢失。

**修复**：传递原始 `anthropic` 对象到 `setNestedScalarContainer()`，添加 `excludeKeys: ANTHROPIC_COLLECTION_KEYS`。

**代码验证**：✅ 已确认。`route.ts:186` 定义 `ANTHROPIC_COLLECTION_KEYS = new Set(["rewrite_system_reminders", "non_deferred_tools"])`，行 565 调用 `setNestedScalarContainer(doc, ["anthropic"], anthropic, { excludeKeys: ANTHROPIC_COLLECTION_KEYS })`。`setNestedScalarContainer`（行 587）逐 key 调用 `setScalar`，跳过 `excludeKeys` 中的 key，collection key 由下方 `replaceCollection` 单独处理。测试（行 695 "preserves untouched anthropic sibling keys during partial updates"）确认发送 `rewrite_system_reminders` 不影响 `strip_server_tools` 和 `context_editing`。

### [LOW] General section 缺少 proxy 的 requires-restart 标注

**代码验证**：✅ 已确认。`VConfigPage.vue:218-233` 的 General `<ConfigSection>` 组件带有 `requires-restart` prop。Rate Limiter section（行 430）同样带有此 prop。

### [VERY LOW] ConfigKeyValueList 空 error DOM 节点

**代码验证**：✅ 已确认。`ConfigKeyValueList.vue:88-98` 使用 `v-if="duplicateKey(index)"` 条件渲染 error div，无重复 key 时不产生 DOM 节点。
