# C0.1 —— 共享 SDK oracle harness

> 开场先读 [README.md](README.md) 的通用红线与必读清单。**本片零生产改动，纯测试。**

## 背景

本项目要把 Anthropic ↔ Responses 的六个方向专用 translator 收敛成「一个 semantic mapper + ledger + 两个 wire emitter」（RFC 2026-08-08）。整条迁移的正确性依赖两个**独立客户端 oracle**：真实的 OpenAI SDK 与真实的 Anthropic SDK —— 它们是唯一能证明「我们发的 wire，真客户端确实能消费」的东西，自洽的 golden 证不了这件事。

好消息是这两个 oracle **在本仓库已经存在**，只是各自内联在一个测试文件里。本片把它们提取成共享模块，供 C0.2 起的全部后续片复用。**不要重造，那会产生第二份会漂移的实现。**

## 现有资产（先读，复核行号）

- `tests/openai/responses-to-anthropic-stream.unit.test.ts:97` `sdkAccumulate` —— 已在用**真** `@anthropic-ai/sdk` 的 `Stream.fromSSEResponse`（Claude Code 用的正是这个解码器），把合成的 wire 喂进去、只从**幸存**的事件重建 `Message`。同文件 `:78` 的 `assertEventLineInvariant` 是 N1 不变量：每帧必带 `event:` 行且为 SDK 可识别名——缺了 SDK 会**静默丢帧**，自洽 golden 抓不到。`:87` `toWire` 做序列化。
- `tests/e2e-client/responses-nodelta.probe.it.test.ts:266` `finalOf` —— 已在用**真** `openai` SDK 的 `client.responses.stream().finalResponse()`，经真实 HTTP（in-process `Bun.serve`）打到真实代理，上游用 `setUpstreamFetchForTests` 挡住。同文件 `:311` 与 `:327` 是**已有的负控**：缺 `content_part.added` 的 `.done` 会让 SDK 抛 `missing content`。这正是 RFC C0 要的红样本。

依赖已在 `package.json`：`openai@6.45.0`、`@anthropic-ai/sdk@0.106.0`。**不要新增包。**

**必须逐条仍绿，且用例数不变**——这是「纯移动」的证明。用例数变了说明你动了断言。
