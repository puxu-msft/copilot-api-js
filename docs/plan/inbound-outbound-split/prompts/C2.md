## 背景 + 为什么

C1 落了 `cell-assembly.ts` 的契约（`OUTBOUND_LEGS`/`RETRY_SEMANTICS` 两穷尽 Record 占位 throw + `resolveCellAssembly` + `MIGRATED_LEGS` 空集 + `env.requestState`），**未接线、零行为变化**。C2 把 **`/v1/messages` 腿**（Anthropic wire）从散布的 `{anthropic codec direct 分支 + strategy-registry anthropic supply + 3 reverse handler 的 reverseBetaProbe/reverseMapperHolder/reverse sanitize}` **提取**进 `AnthropicCellAssembly`，并让 driver 对这条腿走 `resolveCellAssembly`。

**为什么原子**：`/v1/messages` 腿被 **4 route / 4 handler** 触达（messages direct + cc/responses/gemini 反向 @messages）。若只切一部分、旧供料没同 commit 删，会**双 sanitize**（reverse orphan-strip 翻倍）或双活。必须**同一 commit**：加 assembly + driver fork 切这 4 route + 删 4 handler 的旧 /v1/messages 供料 + 删 anthropic codec 的 direct 分支（**保留 forward-translate/ccDelegate 分支**——那是 C3 的事）。

**提取不重写**（`large-refactor` §5 factory 锚点）：算法核（buildAnthropicStrategies / prepareAnthropicRequest / reverse-anthropic-rewrite 三 export / sanitize 链）**原样搬**，只改「谁持有 + 谁调」。

### C2a — direct anthropic cell `(anthropic, /v1/messages)`（最小、最简、先做）
**关键实测发现（主会话已核）**：anthropic codec 的 direct 算法核已是 **3 个近乎纯函数** + 无副作用共享，可零字节分歧提取：
- `prepareAnthropicWire(env, PrepareWireDeps)`（`codec.ts:530`）——deps = `{betaProbe, clientAnthropicBeta, clientRequestHeaders, requestContext, requestedThinkingType}`，全部可从 `env.requestState`（betaProbe/clientAnthropicBeta/clientRequestHeaders）+ `env.ctx`（requestContext）+ `env.requestState.truncateBaseline?.thinking?.type`（requestedThinkingType）取。副作用：`betaProbe.recordOutbound`（R3 惰性）+ `ctx.recordFeature(thinking/cache-control-stripped)` + 返回 `strippedCacheControlSubfields`。
- `anthropicPreSend(env)`（`codec.ts:594`）——**已是纯 env 函数**（只读 `state.autoTruncatePreflight` + env.body/model），零 codec 闭包依赖，直接搬。
- `sampleAnthropicRequest(wire, env)`（`codec.ts:643`）——**已是纯 (wire,env) 函数**，返回 `{requestSample, effectiveMessages}`，零闭包依赖，直接搬。
- `buildAnthropicStrategies(deps)`（`strategies.ts:95`）——deps 从 `env.requestState`（originalPayload=truncateBaseline / resanitize / betaProbe）+ spec.maxRetries 取。
- requestRewrites（direct）= `[createQuarantineProactiveFilter(), createAnthropicSanitizeRewrite({preprocessInfo, onInitialSanitizationInfo→写 ctx})]`。**注意** preprocessInfo 现由 route 供给 codec（`CreateAnthropicCodecArgs.preprocessInfo`），assembly 需另取（放 env.requestState 或 ctx）。
