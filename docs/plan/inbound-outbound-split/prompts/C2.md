## 背景 + 为什么

C1 落了 `cell-assembly.ts` 的契约（`OUTBOUND_LEGS`/`RETRY_SEMANTICS` 两穷尽 Record 占位 throw + `resolveCellAssembly` + `MIGRATED_LEGS` 空集 + `env.requestState`），**未接线、零行为变化**。C2 把 **`/v1/messages` 腿**（Anthropic wire）从散布的 `{anthropic codec direct 分支 + strategy-registry anthropic supply + 3 reverse handler 的 reverseBetaProbe/reverseMapperHolder/reverse sanitize}` **提取**进 `AnthropicCellAssembly`，并让 driver 对这条腿走 `resolveCellAssembly`。

**为什么原子**：`/v1/messages` 腿被 **4 route / 4 handler** 触达（messages direct + cc/responses/gemini 反向 @messages）。若只切一部分、旧供料没同 commit 删，会**双 sanitize**（reverse orphan-strip 翻倍）或双活。必须**同一 commit**：加 assembly + driver fork 切这 4 route + 删 4 handler 的旧 /v1/messages 供料 + 删 anthropic codec 的 direct 分支（**保留 forward-translate/ccDelegate 分支**——那是 C3 的事）。

**提取不重写**（`large-refactor` §5 factory 锚点）：算法核（buildAnthropicStrategies / prepareAnthropicRequest / reverse-anthropic-rewrite 三 export / sanitize 链）**原样搬**，只改「谁持有 + 谁调」。

## 目标改动（原子，同一 commit）
1. **实现 `AnthropicCellAssembly`** 填 `OUTBOUND_LEGS[ENDPOINT.MESSAGES]`（替 C1 占位 throw）：
   - `translateOut(env)`：按 `env.clientFormat` 分派——anthropic=identity；openai-cc/gemini/openai-responses=各 source→Anthropic translateOut（搬现 source codec 的 reverse translateOut 逻辑，或调 hub）。
   - `requestRewrites(env)`：anthropic direct=`[createAnthropicSanitizeRewrite(...)]`（现 codec.getRequestRewrites）；reverse=`[createReverseAnthropicSanitizeRewrite(mapperHolder)]`（mapperHolder 住 env.requestState 或 assembly per-request scratch）。
   - `prepareWire`/`sampleWireTrack`/`preSend`：搬 anthropic codec direct 分支。
   - `buildLegStrategies(spec,env)`：`buildAnthropicStrategies({originalPayload:env.requestState.truncateBaseline, resanitize:env.requestState.resanitize, betaProbe:env.requestState.betaProbe, model, maxRetries:spec.maxRetries})`。
2. **填 `RETRY_SEMANTICS`** 的 MESSAGES-腿部分（anthropic/openai-cc/gemini/openai-responses，后者 R1 corner）；CC/RESPONSES 腿部分本 commit 可仍 throw（C3/C4 接）。
3. **`env.requestState` 由 parse 填**：4 codec 的 parse 在 targetEndpoint 可能是 MESSAGES 时，把 betaProbe（direct=createBetaProbe(clientAnthropicBeta)/reverse=createBetaProbe(undefined)）+ truncateBaseline + resanitize + clientAnthropicBeta + initialSanitizationInfo 写进 env.requestState。**R3**：betaProbe 引用共享、strategy 惰性 getCandidates。
4. **driver hybrid fork**：在 driver 的单槽派发点（translateOut/prepareWire/strategies/requestRewrites/responseRewrites/sampleRequest/preSend），`if (isLegMigrated(env.targetEndpoint)) 用 resolveCellAssembly(env.clientFormat, env.targetEndpoint).<method> else 用 deps.*/codec.*`。**`MIGRATED_LEGS` 加 `ENDPOINT.MESSAGES`**。
5. **删同 commit**：3 reverse handler 的 reverseBetaProbe/reverseMapperHolder/reverse sanitize/reverse strategies supply（MESSAGES 分支）；messages handler 的 buildMessagesDriverStrategies 的 anthropic supply 装配 + betaProbe 注入 driver（改由 env.requestState）；anthropic codec 的 **direct 分支**（`!isForwardTranslateLeg` 部分，保留 forward-translate/ccDelegate 分支给 C3）。
6. **pipelineInfo 经 ctx**：`recordRetryPipelineStateV4` 改从 `ctx` 读（prepareWire/sampleWireTrack/requestRewrites 写 ctx 的 truncateBaseline/effectiveMessages/initialSanitizationInfo/strippedCacheControl），消灭 codec accessor 群。ctx 需加 read-back getter（§11.9 MEDIUM）。
