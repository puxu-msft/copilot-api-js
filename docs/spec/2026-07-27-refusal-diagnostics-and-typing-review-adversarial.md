## Blocker 清单摘要

1. `category:null` 被误建模为“empty/疑似瞬时”，但官方契约明确它是“未映射到命名类别”的正常永久值；核心二分法和可重试性推论失效。
2. `thinking_tokens ?? output_tokens` 不能修复 D3；真实 `bio` 样本已经证明只有 thinking block 时两者仍可相差 212，老样本缺专字段时只能记“未知”。
3. rewrite 层在 processor 创建时捕获策略，handler 终态却读取可热重载的全局 `state`；“两个层都调用同一 resolver”不能保证同一请求内一致，且 buffered retry 的不同 attempt 也可能拿到不同策略。
4. 草案没有定义 refusal delta 后缺 `message_stop`、重复 `message_delta`、终态后还有帧时的单终态规则；`end_turn` 复合截断会实际产生 `message_delta(end_turn)` 后再接 `event:error` 的畸形序列。
